# Prompt 10 — Create Development Plan

```text
Read all accepted source-of-truth documents.
Create docs/development/DEVELOPMENT_PLAN.md using the milestone order in this kit.

For every milestone include:
- goal
- player-visible outcome
- backend work
- database work
- Flutter work
- automated tests
- seed data
- acceptance criteria
- exclusions
- dependencies
- recommended branch
- recommended commits
- rollback considerations

Each milestone must produce a working vertical slice and remain reviewable by one developer.
Do not implement code.
```
